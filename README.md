## 🌐 Live Demo

**👉 [gokulpvtr.github.io/portfolio](https://gokulpvtr.github.io/portfolio/)**

My interactive 3D portfolio website, built with React and Three.js.

| | |
|---|---|
| 🌌 **3D hero** | A network sphere scanned by a moving plane, with 14,000 GPU particles that flow and scatter away from your cursor |
| 🖱️ **Custom cursor** | Comet trail, targeting-reticle ring on buttons, and click shockwaves |
| 🧊 **Glass UI** | Frosted 3D tilt cards, floating glass nav, and social dock |
| 📜 **Scroll effects** | Smooth inertial scrolling, word-by-word reveals, self-drawing timeline, scroll-driven camera |
| ⚡ **Adaptive performance** | Automatically switches to a lighter mode on slower devices (add `?lite` to force it) |
| ♿ **Accessible** | Keyboard focus outlines and a reduce-motion setting |

**Stack:** React 18 · Vite · @react-three/fiber (Three.js) · Framer Motion · Lenis
**Hosting:** GitHub Pages via GitHub Actions

<details>
<summary><b>Run the portfolio locally</b></summary>

<br>

Requires Node.js 18 or newer.

```bash
git clone https://github.com/Gokulpvtr/portfolio.git
cd portfolio
npm install
npm run dev
```

Open the address it prints (usually `http://localhost:5173`). To build for production:

```bash
npm run build     # creates the dist/ folder
npm run preview   # test the built site locally
```

</details>
